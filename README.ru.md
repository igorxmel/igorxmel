Бэкенд-разработчик. В основном Java и Spring Boot, рядом Python.

На стажировке в **hh.ru** делал бэкенд внутренней платформы подбора школ аналитиков - Spring Boot, PostgreSQL с миграциями на Liquibase, MinIO для файлов, всё в Docker с деплоем через GitHub Actions. Там же сделал ИИ-фичу для помощи админам в ревью присылаемых решений.

Бэкенд - основное, но не единственное, что у меня получается. Умею встраивать ИИ-функции в реальные продукты, уверенно работаю с современными инструментами, углубляюсь в DevOps и CI/CD.

Обратная связь, которую я чаще всего слышу от сокомандников и тимлидов, - про продуктовое мышление: мне хорошо даётся придумывать и прорабатывать идеи, а не только реализовывать чужие. Ещё говорят, что со мной легко связаться и что на меня можно положиться, когда что-то ломается на проде.

**Сейчас ищу работу бэкенд-разработчиком.**
